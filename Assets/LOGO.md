# WorshipFlow icon

Generated using the built-in image generation tool. Master: `WorshipFlow.png`.
The build script uses macOS sips and a PNG-to-ICNS container packager to package the master as a multi-resolution ICNS and sets CFBundleIconFile.

## Generation prompt

Use case: logo-brand. Create a polished macOS app icon for WorshipFlow, a church lyrics presentation app with smoothly scrolling lyrics and soft moving waves. One centered rounded-square midnight-indigo tile with generous transparent outer margin. A bold elegant white flowing ribbon forming a W, with three flowing upward wave strokes suggesting rising song. Subtle luminous teal-to-blue accent along the lower ribbon, restrained dimensional depth. Simple distinctive silhouette readable at 32 pixels. Front view, square 1024x1024 composition. No text, no mockup, no extra objects. Transparent outside the rounded-square tile.
